Lockupmark + wordmark
One mark, two weights. Same silhouette, so the swap is invisible. Line at 28px and up — nav, marketing, headers. Solid at 24px and down — favicon, app icon, dense rows. The foliage is currentColor; the apricot bud is fixed.

—What you're dropping in

assets/ tailwind.config.js ← merge the token block (theme.extend) lib/memba_web/ components/brand.ex ← MembaWeb.Brand — sprig/1 + logo/1 components/layouts/root.html.heex ← favicon + Figtree <link> priv/static/images/ favicon.svg ← solid sprig on sage sprig-line.svg sprig-solid.svg ← optional, for <img> use

1Tailwind tokens

Merge into theme.extend. You get sage-50…800, cream, paper, apricot, ink/ink-2/ink-3, line/line-strong, success, the Figtree sans stack, and rounded-btn/card/modal.

On Tailwind v4 (Phoenix 1.8)? Skip the JS config — put the tokens in assets/css/app.css instead:

2Load Figtree

In root.html.heex, in the <head>. (Or self-host into priv/static/fonts and @font-face it — better for privacy and offline.)

3The brand component

Drop brand.ex at lib/memba_web/components/brand.ex, then add import MembaWeb.Brand to the html_helpers/0 block in lib/memba_web.ex so <.logo /> and <.sprig /> work everywhere.

4Favicon

Copy favicon.svg to priv/static/images/, then add the link in root.html.heex. images is already in static_paths/0 by default.

All five files plus this guide live in the brand/ folder of this project — download it and drop the pieces into the paths above. The sprig is already applied across the Memba mocks here (marketing nav & footer, app rail, hub) if you want a reference for placement.
