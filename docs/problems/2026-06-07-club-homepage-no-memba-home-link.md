# Problems

## Club homepage has no path back to the Memba homepage

Observed: 2026-06-07

When someone is on a club homepage, there is no obvious way to navigate back to the main Memba homepage. This can leave visitors stuck in the club-specific context when they want to return to the broader product site.

Expected:

- Club homepages should provide a clear way to navigate back to the Memba homepage.
- Visitors should be able to move between a club page and the main Memba site without relying on browser history or manually editing the URL.
