# Problems / Follow-up Ideas

## Member visibility and editing of email addresses

Date: 2026-06-01

Iteration 016 lets staff manage a person's primary and alternate email addresses, and lets members sign in with any known address. It deliberately does not let members see or edit those addresses themselves.

Problem to explore later: members may need a trustworthy way to see which email addresses Memba knows for them, which one is primary, and possibly request changes. This has privacy, verification, and shared-household implications, so it should be handled as a separate product slice rather than bundled into iteration 016.

Open questions:

- Should members see primary and alternate email addresses in an account/profile page?
- Should members be able to add, remove, or change their primary email address themselves?
- What verification is required before a member-added alternate address can be used for sign-in or inbound email?
- How should shared household email addresses be handled if two people claim the same address?
