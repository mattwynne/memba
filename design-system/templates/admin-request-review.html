Design-system catch-up

Staff request review & convert

The shipped staff screen lists active verified account requests, keeps them clearly separate from automatic club creation, and makes the convert panel addressable from the request-specific notification link.

repo: wireframes/admin-request-review.html
GET /admin/requests Review the active inbox Oldest active verified requests appear first with requester, club, note, and timestamp.
PATCH /admin/requests/:id Open conversion in place The deep link from email opens the same LiveView with a prepared conversion form.
convert_request Create club + first member Staff confirms the club name and slug before Memba sends the welcome sign-in link.
inactive request Handle stale links Converted, rejected, or missing request links show a clear return path to the inbox.
