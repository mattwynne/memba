# Design-system previews

Files in this directory are repo-side previews for the cloud design system. Author them as self-contained static HTML documents that can render without the Phoenix app build.

## Static preview CSS conventions

- Use the prebuilt daisyUI CDN CSS and copy the app theme values into the preview's `:root` block.
- Use daisyUI component and theme classes for controls and primitives, such as `btn`, `card`, `badge`, `input`, `textarea`, `bg-base-100`, `text-base-content`, and `shadow-xl`.
- Do not rely on Tailwind layout, spacing, sizing, typography, flex, or grid utility classes such as `mx-auto`, `max-w-*`, `px-*`, `gap-*`, `text-sm`, `flex`, or `grid`; those utilities are not generated by the static daisyUI CDN CSS and can silently fail.
- Put preview-specific layout, spacing, sizing, and responsive rules in the page's local `<style>` block with semantic classes such as `.request-shell`, `.review-card`, or `.message-grid`.
- Do not link app build output or bespoke shared app CSS (`styles.css`, `memba.css`, `app.css`, etc.). Each preview must include the CDN links and local CSS it needs.

Email previews follow the same self-contained rule, but should use conservative email-safe markup and inline styles rather than daisyUI classes.
