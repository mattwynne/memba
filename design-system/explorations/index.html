Custom club groups — design map

Discovery-stage design for private, admin-created groups in a Memba club (2026-09-12). Everything here is static HTML with mocked data; nothing sends email or touches a backend.

Start here

Interactive prototypeOne file, click through the whole feature as Alice, Bob, Carol, Dan or Eve. Create a group, add / remove / leave, request access, watch the mock outbox.explorations/custom-groups-prototype.html
  1. As Alice (admin): New group → watch the email preview and inline validation update as you type: try “ board ” (duplicate), clear it (blank), then “Huts maintenance” (distinct name, suffixed address).
  2. Board → Members → Add member → Priya. Open Outbox to see her welcome email.
  3. Switch to Eve → Board → Request access. Switch to Alice → Admin: the request is an ordinary conversation.
  4. Switch to Dan (admin, not in Board) → Board: Members only, no Conversations → Add yourself.
  5. As Bob: Board → Members → Remove Alice, then Leave Board. Try Huts & maintenance for the last-member case.
