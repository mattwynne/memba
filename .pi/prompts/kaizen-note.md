---
description: Capture an observed pipeline/workflow imperfection as a docs/kaizen note
argument-hint: "[context]"
---

Use the project-local `kaizen-note` skill to capture this observation in `docs/kaizen/`.

Context supplied with the command:

```
$@
```

If the context is enough, write and commit the kaizen note. Capture what allowed the problem to happen so a later fix can remove the cause and keep it from coming back. Record the workflow step, expected standard, actual abnormality, impact, suspected system weakness, and any obvious prevention idea without turning the note into a solution plan. If important facts are missing, ask only for the missing facts needed to make the note accurate.
